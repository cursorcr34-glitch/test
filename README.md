# Baki Rentacar

Statik rentacar veb-sayti. Layihə HTML, CSS və JavaScript ilə hazırlanıb; əlavə
dependency tələb etmir.

## Fayllar

- `index.html` - saytın əsas strukturu və məzmunu
- `styles.css` - responsive dizayn və vizual komponentlər
- `script.js` - mobil menyu, avtomobil filterləri və rezervasiya forması

## Lokal işə salma

Faylları brauzerdə birbaşa açmaq olar. Lokal server lazım olsa:

```bash
python3 -m http.server 8000
```

Sonra `http://localhost:8000` ünvanına daxil olun.
